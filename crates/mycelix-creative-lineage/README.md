# Mycelix Creative Lineage

STEW-040 is an arts-oriented profile over the general STEW-006 provenance theorem. It does not create a second lineage graph.

```text
creative lineage record
= exact STEW-006 provenance edge
+ arts-oriented relation profile
+ bounded context references
```

The creative kind must agree with the underlying provenance relation. A record cannot call an edge a translation while STEW-006 says `RemixedFrom`, for example.

Context references can preserve instrumentation, tuning, language, performance practice, choreography, material/technique, venue, cultural context, interpretive notes, source editions, or extension data. They are references, not proof.

This crate does not establish authorship, authenticity, originality, ownership, copyright, cultural legitimacy, permission, artistic quality, canonical interpretation, or provenance-evidence validity.
