# Mycelix Living Transmission

STEW-041 records evidence that a living tradition or practice was transmitted without requiring the transmitted knowledge itself to be stored in the record.

```text
transmission recorded
!= transmitted content published
!= tradition authenticated
!= transmitter authorized
!= recipient consent established
!= community mandate established
```

The event targets a logical stewarded subject rather than freezing one canonical representation. Recipient identity may be an opaque principal/collective reference or deliberately withheld. Context is carried through bounded opaque references so culturally or personally sensitive detail does not need to become public metadata.

This is a continuity/evidence primitive, not a credential, cultural-authority system, attendance register, or truth theorem.
