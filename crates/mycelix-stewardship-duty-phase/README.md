# mycelix-stewardship-duty-phase

STEW-010A profiles each exact benefit clause in a STEW-010 reciprocity obligation as one of four execution phases: precondition, concurrent, post-use, or ongoing.

The profile requires exact one-to-one coverage of the obligation's benefit clauses and an opaque basis reference for each phase assignment.

```text
phase assigned != phase authority verified
phase assigned != duty satisfied
```

The crate exists so later authorization code can distinguish a duty that must already be satisfied from one that must be bound or tracked for future performance.
