# Mycelix Stewardship Admission

STEW-008 records profile-relative decisions about STEW-004 claims without turning those records into universal cultural legitimacy or runtime authority.

```text
claim admitted under profile P
!= universally legitimate steward
!= access authority
!= policy authority
!= ownership
!= cultural truth
```

The complete claim is embedded in the record so a decision cannot silently be transplanted to a different target, claimant, represented collective, basis, domain set, or evidence set.

The asserted decider and admission profile are opaque identifiers. This crate does not authenticate either one, establish currentness, implement appeals, or choose among competing admission systems.
