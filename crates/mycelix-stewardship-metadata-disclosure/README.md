# Mycelix Stewardship Metadata Disclosure

STEW-020B is a fail-closed structural admission theorem for publishing a complete STEW-002 public envelope.

It requires at least one explicit disclosure-basis reference for every surface that the v1 envelope necessarily reveals:

- existence;
- exact structural identity;
- public title;
- public summary when present;
- every exact typed envelope reference.

```text
disclosure basis referenced
!= disclosure authority verified
!= community consent verified
!= legal permission verified
!= publication authorized
```

The result is therefore a **publication candidate**, never final authorization.

If existence is protected, callers must not construct this candidate or publish the STEW-002 envelope at all. This v1 theorem also cannot selectively hide the title while keeping an existing STEW-002 envelope public; that requires a future envelope/projection profile.
