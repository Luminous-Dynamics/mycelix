## Explicit acquisition phase

A2PL0 never silently decides whether network access is acceptable. The operator must choose either:

```text
--allow-network
```

or

```text
--offline
```

Network mode may run Cargo resolution/fetch. Offline mode sets Cargo offline and fails if the required registry/Git objects are not already available in the isolated capsule Cargo home.

After resolution/fetch, A2PL0 always runs a second `cargo metadata --locked --offline` probe using the same isolated Cargo home. Failure means the candidate cache is not sufficient for later offline work.
