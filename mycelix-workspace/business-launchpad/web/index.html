What happens to my data?

This static prototype makes no application-level network requests and stores no form inputs. The browser loads the page and its code as ordinary static files; calculations happen in the browser. This is not a hosted account, backup or business record system. Do not use it as the only copy of important information.

Business Launchpad is experimental software. Verify assumptions, source documents, local rules and financial details independently.
