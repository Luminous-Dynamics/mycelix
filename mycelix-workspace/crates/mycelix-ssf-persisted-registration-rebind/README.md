# SSF Persisted Registration Rebind v0.1

This crate converges direct persisted-registration evidence and historical restart reconciliation back onto the exact typed adoption-authority candidate lineage before any authority issuance boundary.

A persisted record alone is insufficient. A rehydrated candidate alone is insufficient. The exact registration subject, durable record, verifier evidence, validity ceilings, and candidate lineage must agree.

The rebound token remains non-authoritative. It explicitly requires a later durable single-use issuance reservation and current authority revalidation before any state-install or effect authority can exist.
