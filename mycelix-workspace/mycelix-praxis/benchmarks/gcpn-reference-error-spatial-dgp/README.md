# GCPN spatial reference-error DGP and pFSS robustness v0.1

This standalone crate holds candidate and reference forecast fields fixed and varies only the verifying observation. It calls the existing `gcpn-probabilistic-fss` scorer through a local path dependency.

## Paradigm shift

A verifying analysis is not silently treated as perfect latent truth. The experiment separates:

1. a synthetic latent event field, known only to the evaluator;
2. a measured/retrieved verifying field generated by a declared observation-error process;
3. candidate and reference forecasts held fixed across error realizations.

The latent field is an oracle diagnostic, not an assertion that latent truth is observable in operational systems.

## Implemented observation-error families

- zero-error control;
- independent bounded measurement noise;
- isotropically spatially correlated noise;
- anisotropic correlated noise as a directional/advected approximation;
- shared common-mode error within a declared event block;
- heteroscedastic noise concentrated near the event threshold;
- event-dependent missingness;
- upper censoring around the event threshold;
- point-to-cell representativeness displacement;
- constant additive bias;
- temporally persistent error components within event blocks;
- threshold-boundary uncertainty.

The spatial kernels use a periodic/toroidal grid boundary. This is an explicit synthetic choice that preserves homogeneous sampling at edges; it is not asserted to represent real geographical boundaries. The current noise generator uses standardized bounded innovations, not an assumed physical sensor-noise distribution.

## What is measured

For each trial and predeclared neighbourhood width, the benchmark records candidate and reference pFSS against both latent truth and the observed reference. It reports:

- candidate-minus-reference pFSS against latent truth;
- the same paired difference against the observed reference;
- rank reversals across observation-error realizations;
- rank-reversal probability with a 95% normal interval computed from independent event-block means;
- observed event frequency and missing-cell counts;
- random-reference p95 calibrated separately from the observed field and the latent field;
- candidate and reference exceedance rates against the observed-field random null.

The independent-Bernoulli random reference is a specific null model, not a universal spatial climatology. Observed and latent event frequencies are kept as separate estimands.

## Unknown parameters

An `UnknownRange` configuration runs lower, midpoint and upper severity values and marks every result `sensitivity_only=true`. It does not estimate or apply a correction, claim the parameter is known, or emit a single falsely precise corrected score.

Rust 1.98.1 is pinned. The crate has no external dependencies beyond the local GCPN pFSS package.

## Qualification boundary

This is a synthetic DGP and scorer-robustness experiment. It does not estimate uncertainty for ERA5, satellite retrievals, rain gauges, radar, or any other actual source. It does not prove forecast superiority or warning value. Spatial/temporal error families are stylized and require validation against authorized observation-network metadata before any real-data correction is attempted.

The benchmark uses repeated event-block realizations; grid cells are never treated as independent replicates for rank-reversal uncertainty. Its block-level normal interval is a Monte Carlo diagnostic, not a general confidence interval for a real forecast population.
