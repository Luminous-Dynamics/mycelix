# Mycelix Craft design documents

This directory contains versioned Craft architecture and qualification proposals.

- [Project Formation V1](PROJECT-FORMATION-V1.md) — need-first project envelopes, contextual capability requirements, participant consent and evidence-aware requirement coverage.
- [Project Formation Benchmarks V1](PROJECT-FORMATION-BENCHMARKS-V1.md) — adversarial conformance, matched team-formation baselines and proposed community-pilot measures.

Related work is tracked by [#6729](https://github.com/Luminous-Dynamics/mycelix/issues/6729), with the wider Capability Commons programme in [#6715](https://github.com/Luminous-Dynamics/mycelix/issues/6715). Governance, professional assessment, plural-economic agreements and Work Evidence have separate reference implementations and ownership boundaries; this crate does not subsume them.

Documents marked proposed or draft are not implementation or qualification claims. Check linked issues and pull requests for current status.
