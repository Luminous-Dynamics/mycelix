## Why the hardened core is real ancestry

Both the provider-policy identity and generic policy-evidence waist depend directly on `mycelix-institutional-core`. Merely documenting #823 as a follow-on would leave an older constructor-bypass-capable core in the executable tree.

This convergence instead imports #823's exact hardened `src/lib.rs` and adversarial validation corpus and makes #823 a real Git parent. Therefore later adapters built on this tree cannot accidentally regress to the unhardened typed-ID semantic boundary without a visible tree change.

## Evidence lifetime remains non-authoritative

#181's `EvidenceLease` is reused unchanged. Its lease intersection may only narrow the verification horizon:

```text

valid_until(join) = min(record, adoption)
```

A lease says only how long already-qualified evidence may be reused. It does not identify the governing policy, prove adoption, establish generation currentness, or grant authority.
