# Mycelix Interoperability Architecture

This directory holds documentation-only interoperability contracts, semantic censuses, and external conformance fixtures used to keep integrations neutral, provenance-preserving, and explicit about authority boundaries.

Current line:

- `MYC_INT_001B_SEMANTIC_CENSUS.md` — inventory and ownership decisions for evidence, epistemics, verification, provenance, and authority semantics.
- `MYC_INT_001C_EPISTEMIC_NAMESPACE_CONTRACT.md` — namespace and loss-aware translation contract for incompatible epistemic schemas.
- `MYC_INT_003A_INTEGRAL_PHASE0_SOURCE_PROFILE.md` — preregistered Integral source hierarchy and Phase-0 registry boundary.
- `fixtures/MYC_INT_003A_INTEGRAL_PHASE0_SOURCE_PROFILE.json` — machine-readable external source/status registry fixture for that boundary.

These documents and fixtures do not by themselves establish executable compatibility, production readiness, semantic equivalence, factual truth, political legitimacy, or authority for external governance/economic systems.
