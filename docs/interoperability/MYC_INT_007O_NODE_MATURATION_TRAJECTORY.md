# MYC-INT-007O — Node Maturation Capability / Dependency Trajectory

Status: design/fixture only. Cross-cutting child of MYC-INT-007I and the 007K–007N seeding line.

## Purpose

Make the public grassroots→productive→resilient→reduced-dependency→seeder story measurable without compressing it into a single maturity or self-sufficiency score.

The first trajectory is explicitly `SyntheticPlannedShowcase`. It is a visualization/test contract, not physical evidence.

## Core rule

```text
more local capability in one domain
!= whole-node independence

lower external dependency in one domain
!= lower external dependency everywhere

N5 seeder capability
!= economic autarky
```

The node remains a vector of domain-specific capabilities and dependencies.

## Dimensions

007O tracks the 007I dimensions independently:

- food;
- water;
- energy;
- repair/fabrication;
- compute/network;
- governance operations;
- evidence/provenance;
- health/safety support;
- external legal/finance dependency;
- critical imports;
- skills/maintainers;
- recovery/spares;
- federation dependency.

## Dependency states

The trajectory uses only the descriptive 007I vocabulary:

- `LocallyAvailable`;
- `LocallyAvailableWithExternalInputs`;
- `ExternallyDependent`;
- `DegradedWithoutExternalSupport`;
- `UnavailableWithoutExternalSupport`;
- `Unknown`.

The states are not summed, averaged, ranked, or converted into one authoritative score.

## Planned A trajectory

### N0 — GrassrootsProtoNode

Most material/service domains are externally dependent. Basic local decision activity can exist while recovery/evidence capabilities remain weak or unknown.

### N1 — InstrumentedNode

Local compute/evidence paths improve. Food, water, energy, health/legal, and critical-import dependencies can remain external.

### N2 — OperationalProductiveNode

At least one real food/water/repair productive loop exists. This does not imply energy, specialist services, critical imports, or legal/financial independence.

### N3 — LocallyResilientNode

Governance/evidence/recovery continuity improves under bounded outages. The node must still show what degrades or stops.

### N4 — ReducedDependencyRegenerativeNode

Selected water/energy/material/repair dependencies improve. Health/legal support and critical imports remain explicit in the planned fixture.

### N5 — SeederNode

The dependency vector may remain substantially the same as N4. The new capability is production of an authority-free, secret-free node seed package under 007K.

```text
seed export capability
!= all external dependencies eliminated
```

## Transition evidence gates

The fixture binds planned evidence classes for:

- N0→N1: acquisition/evidence path + dependency map;
- N1→N2: real productive loop + work/material observations + outcome feedback;
- N2→N3: bounded outage continuity + recovery evidence + local safe stop;
- N3→N4: domain-specific dependency-change evidence + remaining critical imports;
- N4→N5: node seed package + secret-free audit + selective-admission contract.

A future observed trajectory must bind actual evidence instead of merely changing `transition_claim` labels.

## UI contract

The participant/operator view should:

- display each domain separately;
- keep `Unknown` visible;
- show remaining external dependencies;
- preserve trade-offs and regressions;
- distinguish synthetic/planned from observed evidence;
- avoid a single overall maturity or self-sufficiency score.

The visual can still tell a simple story, but the detail view must be able to show, for example:

```text
water dependency ↓
local repair capability ↑
local energy share ↑

while

critical electronics imports remain external
health/specialist support remains external
legal/finance dependency remains external
```

## Nonclaims

007O does not establish observed node maturity, economic independence, ecological sustainability, governance legitimacy, legal compliance, or successful node replication.
