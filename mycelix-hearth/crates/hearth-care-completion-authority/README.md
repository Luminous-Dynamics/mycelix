# Hearth Care Completion Authority

Pure theorem for deciding whether completion evidence may become planner-grade household workload history.

A completion is qualified only when:

1. the underlying Care occurrence is already fully qualified across assignment and recurrence/time authority;
2. completion records agree on performer and actual duration;
3. the performer matches the occurrence assignee; and
4. the completion is self-authored (`recorded_by == performed_by`).

Third-party attestations, conflicts, missing completions, performer mismatches, and completions over unqualified occurrences remain visible but do not become fairness/workload authority.
